# Phase 2 and 3 Lane B integration

Approved scope: finish Today/detail device checks, implement Connected Apps, verify the Phase 2 matrix, then rule engine, activity, rules, approvals, and privacy proof. The shared design spec and boards remain authoritative.

## Design

Steve's merged rule engine, action runner, and queue are reused. No frozen type or bridge contract changes, native edits, new dependencies, calendar sync, or cloud sign-in. SQLite-backed screens use existing query hooks and controls. Channel changes are serialized, native capture is disabled before revocation is persisted, and errors remain visible with retry. App discovery merges installed and stored channels with new apps off at level 1. Failed operations never display success.

Rules initialize the existing three built-ins off; preview counts use decisions over stored messages without taking actions. Activity shows stored outcomes, rule, source, and block reasons. Approvals shows source, editable text, preparation reason, individual confirmation, discard, queued outcomes, and retryable errors. Sending rechecks enabled channel and level 2; duplicate confirmation cannot send twice. Privacy proof reads bridge facts and SQLite counts, and explains debug internet permission honestly. No invented timing metrics: absent durable processing-duration data is reported as unavailable.

## Acceptance

- App switches and level choices persist across reload and synchronize the full enabled package list; off apps cannot create new intake rows even from pending/injected notifications.
- Built-in controls persist and affect decisions for subsequent messages; previews have no side effects.
- Hostile messages never act and have a blocked entry with a reason and original source.
- Only a confirmed draft sends; edits persist; channel revocation and repeated sends are denied; offline confirmation queues.
- Privacy facts update on focus/return and distinguish debug permission from a release without internet.
- Device tests use clearly synthetic fixture messages and restore font scale. Real remote Messenger sends need another account/device and are not simulated as real listener evidence.
